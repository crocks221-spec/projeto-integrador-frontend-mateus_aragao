# Wiki dos Pokémon Iniciais

Este projeto será uma wiki dedicada aos Pokémon iniciais das diferentes gerações.
A página apresentará informações como nome, tipo, região, habilidades e evoluções.
O objetivo é organizar essas informações de forma simples e acessível para os fãs da franquia.
O projeto será desenvolvido durante as aulas de Desenvolvimento Front-end para Web.
